# 后端技术概览

| 缓存 | Redis | 7.0+ | 会话缓存、汇率缓存、限流 |
| 认证 | JWT (golang-jwt) | v5 | 无状态 Token 认证 |
| 配置 | Viper | v1.18+ | 多格式配置管理 |
| 日志 | Zap | v1.27+ | 高性能结构化日志 |
| 定时任务 | robfig/cron | v3 | 定期交易、账单提醒、汇率更新 |
| 校验 | validator | v10 | 请求参数校验 |
| 文档 | Swag | v1.16+ | Swagger/OpenAPI 自动生成 |

## 设计原则

1. **复式记账原则**：每笔交易必须包含借方和贷方两条记录，金额绝对值相等
2. **多租户隔离**：所有业务数据通过 `user_group_id` 隔离，查询自动注入租户条件
3. **API 优先**：后端仅提供 RESTful API，不渲染页面
4. **规则引擎异步执行**：交易创建/更新后异步触发规则引擎，不阻塞主流程
5. **软删除**：关键实体使用软删除（deleted_at），保留审计追溯
6. **乐观锁**：并发更新场景使用版本号控制
