# 前端技术概览

## 技术栈选型

| 层次 | 技术 | 版本要求 | 说明 |
|------|------|----------|------|
| 框架 | Vue | 3.4+ | Composition API + `<script setup>` |
| 构建工具 | Vite | 5.x | 极速 HMR、按需编译 |
| 语言 | TypeScript | 5.x | 类型安全 |
| 路由 | Vue Router | 4.x | 路由管理、导航守卫 |
| 状态管理 | Pinia | 2.x | 轻换 Vuex，更优 TS 支持 |
| UI 组件库 | Element Plus | 2.x | 企业级 Vue3 组件库 |
| 图表 | ECharts | 5.x | 数据可视化 |
| HTTP 客户端 | Axios | 1.x | 请求拦截、Token 刷新 |
| 表单校验 | VeeValidate + Yup | 4.x / 1.x | 声明式表单校验 |
| 日期处理 | Day.js | 1.x | 轻换 Moment，更轻量 |
| 金额处理 | decimal.js | 10.x | 高精度金额计算 |
| 国际化 | Vue I18n | 9.x | 多语言支持 |
| CSS 方案 | UnoCSS | 0.x | 原子化 CSS，按需生成 |
| 图标 | @iconify/vue | - | 统一图标方案 |

## 设计原则

1. **API 驱动**：前端仅消费后端 API，不包含业务逻辑
2. **类型安全**：所有 API 请求/响应使用 TypeScript 类型定义
3. **组合式 API**：全面使用 `<script setup>` + Composition API
4. **按需加载**：路由级代码分割，组件按需导入
5. **响应式优先**：移动端适配，响应式布局
6. **国际化**：所有用户可见文本通过 i18n 管理
7. **金额精度**：所有金额使用 decimal.js 处理，避免浮点误差
