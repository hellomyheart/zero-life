# 账户体系

## 账户类型

Firefly III 定义了 14 种账户类型，分为以下几大类：

### 资产类账户（可拥有余额）

| 账户类型 | 说明 | 典型用途 |
|----------|------|----------|
| Asset account（资产账户） | 主要资产账户 | 银行储蓄卡、活期账户 |
| Default account（默认账户） | 默认类型的资产账户 | 通用资产账户 |
| Cash account（现金账户） | 现金资产账户 | 随身现金 |
| Credit card（信用卡） | 信用卡资产账户 | 信用卡（负余额表示欠款） |
| Saving account（储蓄账户） | 储蓄型资产账户 | 定期存款 |
| Shared asset（共享资产） | 共享型资产账户 | 共同账户 |

### 负债类账户

| 账户类型 | 说明 | 典型用途 |
|----------|------|----------|
| Debt（债务） | 一般债务 | 个人借款 |
| Loan（贷款） | 贷款 | 消费贷款 |
| Mortgage（抵押贷款） | 房贷 | 住房按揭 |

### 系统类账户

| 账户类型 | 说明 | 用途 |
|----------|------|------|
| Initial balance account（期初余额账户） | 系统生成 | 记录账户初始余额 |
| Reconciliation account（对账账户） | 系统生成 | 记录对账差异 |
| Import account（导入账户） | 系统生成 | 数据导入临时账户 |
| Liability credit account（负债信用账户） | 系统生成 | 负债减少记录 |
| Beneficiary account（受益人账户） | 已弃用 | 旧版兼容 |

### 收支类账户

| 账户类型 | 说明 | 典型用途 |
|----------|------|----------|
| Expense account（支出账户） | 支出目标 | 商店、服务商 |
| Revenue account（收入账户） | 收入来源 | 雇主、客户 |

## 账户角色

资产账户可以设置以下角色：

| 角色 | 说明 |
|------|------|
| defaultAsset | 默认资产账户 |
| sharedAsset | 共享资产账户 |
| savingAsset | 储蓄账户 |
| ccAsset | 信用卡账户 |
| cashWalletAsset | 现金钱包账户 |

## 信用卡类型

| 类型 | 说明 |
|------|------|
| monthlyFull | 每月全额还款 |

## 账户属性

每个账户包含以下信息：

### 基本信息
- 名称
- 账户类型
- 账户角色（仅资产类）
- 账户组（Object Group）
- 是否虚拟账户（不参与余额计算）
- 是否活跃

### 金额信息
- 期初余额
- 当前余额（自动计算）
- 虚拟余额（显示用）

### 币种信息
- 默认币种
- 币种小数位数

### 附加信息
- 备注（Note）
- 附件（Attachment，多个）
- 位置信息（Location：经度、纬度、缩放级别）
- 元数据（AccountMeta：键值对）

### 负债特有属性
- 利息率
- 利息周期（daily/weekly/monthly/quarterly/half-year/yearly）
- 信用日期

## 账户元数据

账户可存储任意键值对元数据，常见字段包括：

- `account_role` - 账户角色
- `cc_type` - 信用卡类型
- `cc_monthly_payment_date` - 信用卡还款日
- `currency_id` / `currency_code` - 币种
- `interest` - 利率
- `interest_period` - 利息周期
- `liability_direction` - 负债方向
- `liability_type` - 负债类型

## 账户与交易类型的关系

不同账户类型可以参与的交易类型有严格限制：

| 账户类型 | 可作为支出源 | 可作为收入目标 | 可作为转账方 |
|----------|-------------|---------------|-------------|
| Asset account | 是 | 是 | 是 |
| Cash account | 是 | 是 | 是 |
| Credit card | 是 | 是 | 是 |
| Debt/Loan/Mortgage | 是 | 是 | 是 |
| Expense account | 是（仅目标） | - | - |
| Revenue account | - | 是（仅来源） | - |

## 对象分组

账户可以通过 Object Group 进行分组排序，同一分组可包含账户、账单和储蓄罐。分组具有：
- 标题
- 排序顺序
