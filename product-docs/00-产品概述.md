# Zero-Life 产品概述

## 产品定位

Zero-Life 是一款开源的个人财务管理软件，基于复式记账（Double-Entry Bookkeeping）原则构建。它帮助用户追踪支出、管理预算、记录收入，并提供全面的财务洞察与分析能力。

## 核心设计理念

### 1. 复式记账

每一笔交易都有两个方向：资金来源（Source）和资金去向（Destination）。这确保了账目始终平衡，不会出现资金凭空出现或消失的情况。

- **支出（Withdrawal）**：资金从资产账户流向支出账户
- **收入（Deposit）**：资金从收入账户流向资产账户
- **转账（Transfer）**：资金在两个资产账户之间流动

### 2. 多租户与分组

支持多用户使用，每个用户可以属于一个或多个用户组（Administration），组内通过角色权限控制访问。

### 3. 多币种原生支持

系统原生支持多币种，每笔交易可同时记录本币金额和外币金额，并支持汇率转换。

### 4. 自动化规则引擎

提供强大的规则引擎，可根据条件自动对交易执行操作，实现财务管理的自动化。

## 功能模块总览

| 模块 | 说明 |
|------|------|
| 账户管理 | 管理各类资产、负债、收入、支出账户 |
| 交易记录 | 记录支出、收入、转账等各类交易 |
| 预算管理 | 设定预算限额，追踪预算执行情况 |
| 账单/订阅 | 管理定期账单和订阅服务 |
| 储蓄罐 | 设定储蓄目标，追踪储蓄进度 |
| 分类与标签 | 通过分类和标签组织交易 |
| 规则引擎 | 自动化处理交易 |
| 定期交易 | 管理循环发生的交易 |
| 多币种 | 支持多种货币及汇率转换 |
| 报表与洞察 | 提供财务报表和数据分析 |
| 数据导入导出 | 支持数据导入和导出 |
| Webhook | 事件触发的 HTTP 回调通知 |
| 通知系统 | 邮件、Slack、Pushover 通知 |

## 支持的语言

计划支持超过 30 种语言，当前实现中文（简体）和英文，后续可扩展：中文繁体、荷兰语、德语、法语、西班牙语、葡萄牙语、意大利语、日语、韩语、俄语等。
