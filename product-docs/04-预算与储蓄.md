# 预算、储蓄罐与账单

## 1. 预算管理

### 预算（Budget）

预算用于控制特定类别的支出总额。

| 属性 | 说明 |
|------|------|
| 名称 | 预算名称 |
| 自动预算类型 | auto_budget_type（1=RESET, 2=ROLLOVER, 3=ADJUSTED） |
| 自动预算金额 | auto_budget_amount |
| 自动预算周期 | auto_budget_period（daily/weekly/monthly/quarterly/half-year/yearly） |
| 排序 | 显示顺序 |
| 活跃状态 | 是否启用 |

预算可关联：
- 预算限额（BudgetLimit）
- 交易日志和交易
- 备注
- 附件

### 预算限额（BudgetLimit）

预算限额定义了在特定时间段内的预算上限。

| 属性 | 说明 |
|------|------|
| budget_id | 所属预算 |
| start_date | 限额开始日期 |
| end_date | 限额结束日期 |
| amount | 限额金额 |
| transaction_currency_id | 限额币种 |
| native_amount | 本币金额 |

每个预算在不同时间段可以设置不同的限额。系统会自动计算该时间段内的实际支出，并与限额对比。

### 自动预算（AutoBudget）

自动预算功能可以自动为每个周期设置预算限额。

| 类型 | 值 | 说明 |
|------|-----|------|
| RESET | 1 | 每周期重置为设定金额 |
| ROLLOVER | 2 | 未用完的金额顺延到下周期 |
| ADJUSTED | 3 | 基于实际支出调整，未用完顺延 |

### 可用预算（AvailableBudget）

记录用户在特定时间段内可用的总预算金额。

| 属性 | 说明 |
|------|------|
| transaction_currency_id | 币种 |
| amount | 可用金额 |
| start_date | 开始日期 |
| end_date | 结束日期 |
| native_amount | 本币金额 |

## 2. 储蓄罐（Piggy Bank）

储蓄罐用于设定储蓄目标并追踪进度。

### 储蓄罐属性

| 属性 | 说明 |
|------|------|
| 名称 | 储蓄罐名称 |
| 目标金额 | target_amount |
| 本币目标金额 | native_target_amount |
| 当前金额 | current_amount（直接存储在储蓄罐模型上） |
| 关联账户 | account_id（一对一，每个储蓄罐关联一个账户） |
| 起始日期 | start_date |
| 目标日期 | target_date |
| 排序 | order |
| 活跃状态 | active |
| 币种 | transaction_currency_id |

### 储蓄罐关联

- 关联账户（一对一，通过 account_id）
- 储蓄事件（PiggyBankEvent）
- 备注
- 附件
- 对象分组

### 储蓄事件（PiggyBankEvent）

记录每次存入或取出储蓄罐的操作。

| 属性 | 说明 |
|------|------|
| piggy_bank_id | 所属储蓄罐 |
| transaction_journal_id | 关联交易 |
| amount | 变动金额（正为存入，负为取出） |

## 3. 账单/订阅（Bill）

账单用于追踪定期发生的支出，如房租、水电费、订阅服务等。

### 账单属性

| 属性 | 说明 |
|------|------|
| 名称 | 账单名称 |
| 匹配规则 | match（用于自动匹配交易） |
| 最低金额 | amount_min |
| 最高金额 | amount_max |
| 本币最低金额 | native_amount_min |
| 本币最高金额 | native_amount_max |
| 日期 | date（下次预期日期） |
| 结束日期 | end_date |
| 延期日期 | extension_date |
| 重复频率 | repeat_freq（daily/weekly/monthly/quarterly/half-year/yearly） |
| 跳过次数 | skip（每 N 次跳过） |
| 自动匹配 | automatch |
| 活跃状态 | active |
| 币种 | transaction_currency_id |

### 账单关联

- 交易日志（已匹配的交易）
- 备注
- 附件
- 对象分组

### 账单提醒

系统会在账单到期前发送提醒，提醒周期为：

| 提前天数 | 说明 |
|----------|------|
| 90 天 | 3 个月提醒 |
| 30 天 | 1 个月提醒 |
| 14 天 | 2 周提醒 |
| 7 天 | 1 周提醒 |
| 0 天 | 当天提醒 |

### 账单匹配

账单通过匹配规则自动关联交易。当新交易创建时，系统会检查其描述、金额和日期是否与账单的匹配规则相符，如果匹配则自动关联。

### 重复周期

| 周期 | 说明 |
|------|------|
| daily | 每天 |
| weekly | 每周 |
| monthly | 每月 |
| quarterly | 每季度 |
| half-year | 每半年 |
| yearly | 每年 |

## 4. 分类（Category）

分类用于组织交易，每笔交易可归属一个分类。

| 属性 | 说明 |
|------|------|
| 名称 | 分类名称 |

分类可关联：
- 交易日志和交易
- 备注
- 附件
- 周期统计

## 5. 标签（Tag）

标签用于灵活标记交易，每笔交易可以有多个标签。

| 属性 | 说明 |
|------|------|
| tag | 标签文本 |
| date | 标签日期 |
| description | 标签描述 |
| tag_mode | 标签模式 |

标签可关联：
- 交易日志
- 附件
- 位置信息
- 周期统计

## 6. 周期统计（PeriodStatistic）

系统预计算周期统计数据以优化报表性能。

| 属性 | 说明 |
|------|------|
| start | 周期开始 |
| end | 周期结束 |

周期统计通过多态关联可附加到：
- 账户
- 分类
- 标签
