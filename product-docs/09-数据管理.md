# 数据管理

## 数据导出

系统支持将各类财务数据导出为文件，便于备份和迁移。

### 可导出的数据类型

| 数据类型 | 说明 |
|----------|------|
| 账户 | 所有账户及其元数据 |
| 账单 | 所有账单/订阅 |
| 预算 | 预算及限额 |
| 分类 | 所有分类 |
| 储蓄罐 | 储蓄罐及事件 |
| 定期交易 | 所有定期交易配置 |
| 规则 | 规则及规则组 |
| 标签 | 所有标签 |
| 交易 | 所有交易记录 |

### 导出格式

- CSV 格式（主要）
- 每种数据类型独立导出

## 数据导入

系统支持从多种来源导入数据。

### 导入方式

| 方式 | 说明 |
|------|------|
| CSV 文件导入 | 通用 CSV 文件解析导入 |
| Spectre 导入 | 通过 Salt Edge Spectre API 导入银行数据 |
| Nordigen 导入 | 通过 GoCardless/Nordigen API 导入银行数据 |
| bunq 导入 | 通过 bunq API 导入 |

### CSV 导入配置

CSV 导入支持配置：
- 文件格式（分隔符、引号、转义）
- 列映射（将 CSV 列映射到系统字段）
- 日期格式
- 币种处理
- 重复检测规则

### 导入过程

1. 上传导入文件
2. 配置列映射
3. 预览导入数据
4. 确认并执行导入
5. 查看导入结果报告

### 重复检测

系统通过导入哈希（import_hash / import_hash_v2）检测重复记录，防止同一数据被重复导入。

## 数据销毁

### 销毁数据（data/destroy）

选择性销毁指定类型的数据，保留其他数据。

### 清除数据（data/purge）

彻底清除所有用户数据，包括：
- 所有交易
- 所有账户
- 所有预算
- 所有分类和标签
- 所有规则
- 所有其他财务数据

## 批量操作

### 批量更新交易

支持对多笔交易同时执行操作：
- 批量修改分类
- 批量修改预算
- 批量添加/移除标签
- 批量修改备注

## 定期交易（Recurrence）

定期交易用于自动创建循环发生的交易记录。

### 定期交易属性

| 属性 | 说明 |
|------|------|
| title | 标题 |
| description | 描述 |
| transaction_type_id | 交易类型 |
| first_date | 首次执行日期 |
| repeat_until | 重复截止日期 |
| latest_date | 最近执行日期 |
| repetitions | 重复次数 |
| apply_rules | 创建后是否触发规则 |
| is_active | 是否启用 |

### 重复模式（RecurrenceRepetition）

| 属性 | 说明 |
|------|------|
| repetition_type | 重复类型 |
| repetition_moment | 重复时刻 |
| repetition_skip | 跳过间隔 |
| weekend | 周末处理方式 |

**重复类型：**
- `daily` - 每天
- `weekly` - 每周（指定星期几）
- `monthly` - 每月（指定日期）
- `ndom` - 每月第 N 个星期 D
- `yearly` - 每年（指定月日）

**周末处理：**

| 值 | 说明 |
|----|------|
| 1 | 保持原日期（可能在周末） |
| 2 | 跳到前一个周五 |
| 3 | 跳到后一个周一 |
| 4 | 跳到前一个周五（不跨月） |

### 交易模板（RecurrenceTransaction）

每条定期交易包含交易模板，定义了生成交易时的参数：

| 属性 | 说明 |
|------|------|
| currency_id | 币种 |
| foreign_currency_id | 外币 |
| source_id | 来源账户 |
| destination_id | 目标账户 |
| amount | 金额 |
| foreign_amount | 外币金额 |
| description | 描述 |

### 交易模板元数据（RecurrenceTransactionMeta）

交易模板可存储额外元数据：
- 分类
- 预算
- 标签
- 备注
- 外部 ID

### 定期交易元数据（RecurrenceMeta）

定期交易本身的元数据，如：
- 账单关联
- 币种设置
- 分组标记

## 附件系统

附件采用多态关联，可附加到以下实体：

- Account（账户）
- Bill（账单）
- Budget（预算）
- Category（分类）
- PiggyBank（储蓄罐）
- Tag（标签）
- Transaction（交易）
- TransactionJournal（交易日志）
- Recurrence（定期交易）

### 附件属性

| 属性 | 说明 |
|------|------|
| filename | 文件名 |
| mime | MIME 类型 |
| title | 标题 |
| description | 描述 |
| size | 文件大小 |
| md5 | MD5 校验 |
| uploaded | 是否已上传 |

### 附件操作

1. 创建附件记录（POST /attachments）
2. 上传文件内容（POST /attachments/{id}/upload）
3. 下载文件（GET /attachments/{id}/download）

## 备注系统

备注采用多态关联，可附加到以下实体：

- Account（账户）
- Bill（账单）
- Budget（预算）
- Category（分类）
- PiggyBank（储蓄罐）
- Tag（标签）
- TransactionJournal（交易日志）
- Recurrence（定期交易）
- TransactionJournalLink（交易链接）

| 属性 | 说明 |
|------|------|
| title | 备注标题 |
| text | 备注内容 |

## 位置系统

位置采用多态关联，可附加到以下实体：

- Account（账户）
- Tag（标签）
- TransactionJournal（交易日志）

| 属性 | 说明 |
|------|------|
| latitude | 纬度 |
| longitude | 经度 |
| zoom_level | 缩放级别 |
