# 交易模型

## 交易层级

Zero-Life 的交易采用三层结构：

```
TransactionGroup（交易组）
  └── TransactionJournal（交易日志）× N
        └── Transaction（交易）× 2
```

### TransactionGroup（交易组）

交易组是最外层容器，用于将相关的交易日志组织在一起。

| 属性 | 说明 |
|------|------|
| id | 唯一标识 |
| user_id | 所属用户 |
| user_group_id | 所属用户组 |
| title | 交易组标题（可选） |

一个交易组包含一个或多个交易日志。当一笔交易被拆分时，所有子交易属于同一个交易组。

### TransactionJournal（交易日志）

交易日志记录交易的元信息，是交易的核心描述层。

| 属性 | 说明 |
|------|------|
| id | 唯一标识 |
| user_id | 所属用户 |
| user_group_id | 所属用户组 |
| transaction_type_id | 交易类型 |
| bill_id | 关联账单 |
| transaction_currency_id | 交易币种 |
| description | 交易描述 |
| date | 交易日期 |
| completed | 是否完成 |
| order | 排序顺序 |
| tag_count | 标签数量 |

交易日志可关联的实体：
- 附件（Attachment）
- 标签（Tag，多对多）
- 分类（Category，多对多）
- 预算（Budget，多对多）
- 备注（Note）
- 位置（Location）
- 账单（Bill）
- 交易日志链接（TransactionJournalLink）
- 审计日志（AuditLogEntry）

### Transaction（交易）

交易记录具体的资金流动，每条交易日志包含两条交易记录（借方和贷方）。

| 属性 | 说明 |
|------|------|
| id | 唯一标识 |
| account_id | 关联账户 |
| transaction_journal_id | 所属交易日志 |
| description | 交易描述（可覆盖日志描述） |
| amount | 金额（正数为贷方，负数为借方） |
| native_amount | 本币金额 |
| foreign_amount | 外币金额 |
| native_foreign_amount | 外币的本币等值 |
| transaction_currency_id | 交易币种 |
| foreign_currency_id | 外币币种 |
| identifier | 拆分标识 |
| reconciled | 是否已对账 |

## 交易类型与账户映射

### 支出（Withdrawal）

```
来源：Asset / Cash / Credit card / Debt / Loan / Mortgage
目标：Expense / Cash / Debt / Loan / Mortgage
```

### 收入（Deposit）

```
来源：Revenue / Cash / Debt / Loan / Mortgage
目标：Asset / Cash / Credit card / Debt / Loan / Mortgage
```

### 转账（Transfer）

```
来源：Asset / Cash / Credit card / Debt / Loan / Mortgage
目标：Asset / Cash / Credit card / Debt / Loan / Mortgage
（来源和目标不能相同）
```

## 交易日志元数据

交易日志可存储结构化元数据（journal_meta），常见字段包括：

### SEPA 支付信息
- `sepa_cc` - SEPA 信用卡号
- `sepa_ct_op` - SEPA 对方账户
- `sepa_ct_id` - SEPA 对方 ID
- `sepa_ct_name` - SEPA 对方名称
- `sepa_db` - SEPA 借记
- `sepa_country` - SEPA 国家
- `sepa_ep` - SEPA 外部目的
- `sepa_ci` - SEPA 债权人 ID
- `sepa_batch_id` - SEPA 批次 ID

### 日期信息
- `interest_date` - 利息日期
- `book_date` - 记账日期
- `process_date` - 处理日期
- `due_date` - 到期日期
- `payment_date` - 支付日期
- `invoice_date` - 发票日期

### 导入信息
- `import_hash` - 导入哈希（防重复）
- `import_hash_v2` - 导入哈希 V2
- `import_id` - 导入 ID
- `external_id` - 外部 ID
- `external_url` - 外部 URL

### 定期交易信息
- `recurrence_id` - 来源定期交易 ID
- `recurrence_total` - 定期交易总数
- `recurrence_count` - 定期交易计数

## 交易链接

交易日志之间可以建立链接关系，通过 LinkType 定义：

| 链接类型 | 正向名称 | 反向名称 |
|----------|----------|----------|
| Related | 相关 | 相关 |
| Refund | 退款 | 被退款 |
| Paid | 支付 | 被支付 |
| Reimbursement | 报销 | 被报销 |

链接类型可自定义，每个链接类型包含：
- name - 名称
- inward - 反向描述
- outward - 正向描述
- editable - 是否可编辑

## 交易对账

交易可以标记为已对账（reconciled），表示该交易已与银行对账单核对一致。

## 审计日志

系统对重要操作记录审计日志（AuditLogEntry），包含：
- 被审计对象（auditable）
- 操作者（changer）
- 变更前数据（before）
- 变更后数据（after）
