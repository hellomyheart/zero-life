# 核心功能

## 1. 交易管理

### 交易层级结构

交易采用三层结构组织：

- **TransactionGroup（交易组）**：最外层，包含一组相关的交易日志，可设置标题
- **TransactionJournal（交易日志）**：中间层，记录交易的元信息（日期、描述、类型、账单等）
- **Transaction（交易）**：最内层，记录具体的资金流动（账户、金额、币种）

一个交易组可以包含多个交易日志（如拆分交易），每个交易日志包含两条交易记录（借方和贷方）。

### 交易类型

| 类型 | 说明 | 资金流向 |
|------|------|----------|
| Withdrawal（支出） | 资金流出 | 资产账户 → 支出账户 |
| Deposit（收入） | 资金流入 | 收入账户 → 资产账户 |
| Transfer（转账） | 账户间转移 | 资产账户 → 资产账户 |
| Opening Balance（期初余额） | 初始余额设置 | 系统生成 |
| Reconciliation（对账） | 账目核对 | 系统生成 |
| Liability Credit（负债信用） | 负债减少 | 负债账户 → 资产账户 |

### 交易属性

每笔交易可关联以下信息：

- 描述信息（主描述 + 交易描述）
- 日期与时间
- 来源账户与目标账户
- 金额（本币 + 可选外币）
- 分类（Category）
- 预算（Budget）
- 标签（Tag，多个）
- 账单（Bill）
- 备注（Note）
- 附件（Attachment，多个）
- 位置信息（Location）
- 内部引用与外部 ID
- SEPA 支付信息

### 拆分交易

一笔交易可以拆分为多个子交易（Split Transaction），每个子交易可以有不同的分类、预算、标签、描述和金额，但共享相同的日期和交易类型。

## 2. 搜索系统

### 搜索操作符

系统提供 60+ 个搜索操作符，支持精确搜索交易和账户：

**金额相关：**
- `amount_is` / `amount` - 精确金额
- `amount_min` / `amount_max` - 金额范围
- `foreign_amount_is` - 外币金额

**账户相关：**
- `account_is` - 指定账户
- `source_is` / `destination_is` - 来源/目标账户
- `account_contains` - 账户名包含

**日期相关：**
- `date_on` / `date_before` / `date_after` - 日期筛选
- `interest_date_on` / `book_date_on` / `process_date_on` - 特殊日期

**分类与标签：**
- `category_is` - 指定分类
- `tag_is` - 指定标签
- `has_any_category` / `has_any_tag` - 存在性检查

**状态相关：**
- `reconciled` - 已对账
- `on_budget` / `not_on_budget` - 预算状态

**其他：**
- `description_contains` / `description_is` - 描述搜索
- `notes_contain` - 备注搜索
- `attachment_name_contains` - 附件搜索
- `has_attachments` - 有附件

## 4. 图表与可视化

### 账户图表
- 资产账户余额趋势图
- 账户支出/收入概览

### 预算图表
- 预算使用情况概览
- 预算限额与实际支出对比

### 分类图表
- 分类支出/收入概览

### 仪表盘
- 资产账户总览
- 基本财务摘要
- 待处理账单提醒
- 储蓄罐进度

## 5. 财务管理

系统支持管理负债类账户（Debt、Loan、Mortgage），可以：

- 追踪负债余额变化
- 记录还款交易
- 计算利息
- 查看负债趋势

## 6. 对账功能

支持账户对账（Reconciliation），将银行对账单与系统记录进行比对：

- 创建对账交易
- 标记已对账的交易
- 识别差异
