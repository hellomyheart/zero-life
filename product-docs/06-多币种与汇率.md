# 多币种与汇率

## 概述

Zero-Life 原生支持多币种体系。每笔交易可以同时记录本币金额和外币金额，系统通过汇率转换确保所有金额可以统一展示和统计。

## 货币（TransactionCurrency）

| 属性 | 说明 |
|------|------|
| name | 货币全名（如 "Euro"） |
| code | 货币代码（如 "EUR"） |
| symbol | 货币符号（如 "€"） |
| decimal_places | 小数位数 |
| enabled | 是否启用 |

### 货币关联

- 用户（多对多，通过 pivot 记录 user_default 标识默认币种）
- 用户组
- 交易日志
- 交易
- 预算限额

### 默认货币

系统有一个全局默认货币，每个用户也可以设置自己的默认货币。用户启用的货币列表决定了该用户可用的货币范围。

### 货币操作

| 操作 | 说明 |
|------|------|
| 启用货币 | 将货币添加到用户的可用列表 |
| 禁用货币 | 从用户的可用列表移除 |
| 设为默认 | 设置为用户的默认货币 |

## 交易中的多币种

每笔交易（Transaction）包含以下金额字段：

| 字段 | 说明 |
|------|------|
| amount | 交易金额（交易币种） |
| native_amount | 本币等值金额 |
| foreign_amount | 外币金额（可选） |
| native_foreign_amount | 外币的本币等值金额 |
| transaction_currency_id | 交易币种 |
| foreign_currency_id | 外币币种（可选） |

### 金额记录规则

1. **同币种交易**：amount 记录金额，native_amount = amount
2. **跨币种交易**：amount 记录主币种金额，foreign_amount 记录外币金额
3. **本币转换**：native_amount 和 native_foreign_amount 通过汇率计算得出

## 汇率（CurrencyExchangeRate）

| 属性 | 说明 |
|------|------|
| user_id | 所属用户 |
| user_group_id | 所属用户组 |
| from_currency_id | 源币种 |
| to_currency_id | 目标币种 |
| date | 汇率日期 |
| rate | 汇率值 |

### 汇率查询

汇率按日期记录，查询时使用指定日期或最近的历史汇率。

## 多币种在各模块中的体现

### 预算限额
- amount：限额币种金额
- native_amount：本币等值

### 可用预算
- amount：可用币种金额
- native_amount：本币等值

### 自动预算
- amount：自动预算币种金额
- native_amount：本币等值

### 账单
- amount_min / amount_max：账单币种金额范围
- native_amount_min / native_amount_max：本币等值范围

### 储蓄罐
- target_amount：目标币种金额
- native_target_amount：本币等值

## 汇率 API

| 操作 | 说明 |
|------|------|
| 获取汇率 | 按源币种、目标币种和日期查询 |
| 设置汇率 | 手动设置指定日期的汇率 |
| 列出汇率 | 分页列出所有汇率记录 |
| 删除汇率 | 删除指定汇率记录 |
